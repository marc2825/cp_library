# 基本ユーティリティの14モード

[図を開く](index.html) / [API・使用例・検証](../../docs/utility_search/README.md) / [図解一覧](../README.md)

JSON入力、前後移動、先頭・最後、自動再生を備えています。各モードから対応APIへ移動できます。入力は表示・計算量を制限するため小さめに制約し、不正入力は画面上で報告します。

| モード | 観察する状態 | 図の制約・C++との違い |
|---|---|---|
| 尺取り | 左右端・和・有効区間数 | 非負列40要素まで、区間和の上限制約 |
| 最大部分配列 | 右端で終わる和・復元区間 | 40要素、有限な小整数 |
| 動的MEX | 頻度・欠損値 | 80操作。図は0から走査、C++は被覆区間集合 |
| 半分全列挙 | 両半分の部分和・組合せ | 16要素。表の表示は先頭32件、組合せは図の小入力を全走査。C++は単調な境界を使用 |
| 順列演算 | サイクル・逆・冪 | 40要素、指数は64bit文字列も可 |
| 黄金分割・フィボナッチ | 評価点・候補区間・評価回数 | methodで切替、目的関数は絶対値。JSはdouble、C++実数版はlong double |
| 集合hash | 頻度・2本のhash | int64キーとuint64 seedを文字列で入力。BigIntでC++と同じwrapを再現 |
| 順列木 | 共通区間・強共通区間・節点の型と子 | 12要素。構造の定義を全区間列挙で示すモデル。C++の単調スタック・セグメント木の高速構築の逐語再現ではない |
| 括弧 | 開き括弧で始まる補完数・残り順位・木 | 30組。順位・個数はBigInt |
| 整数分割 | 部分列の次状態 | n≤100、先頭100件まで。全件数と打切りを表示 |
| 集合分割 | RGSと具体的ブロック | n≤20、先頭100件まで。全件数と打切りを表示 |
| 部分永続 | 版ごとの配列・時刻の二分探索 | 20要素・60更新。図は全版をコピーし、条件の単調性も確認。C++は添字ごとの変更履歴 |
| 過去操作編集 | 各時刻のaffine変換と直後の値・任意時点の値 | 時刻30個、60編集。BigIntで順に再実行するモデル。C++はMonoidとSegtreeで合成 |
| 特殊整数列挙 | 回文の反転・数字のprefix・積の次候補 | kindはpalindrome/digits/products、先頭100件。uint64を文字列で指定。積は図では候補集合、C++では複数ポインタのマージ |

`verify/visualizations/utility_search_model_test.js` で14のC++結果と比較し、全列挙・ランダム入力・範囲外入力も検証します。`utility_search_browser_test.mjs` はChromiumで全モード、入力変更、前後・再生、エラー復帰、ローカルリンク、幅390pxを確認します。実行状況は[検証記録](../../docs/utility_search/README.md)へ記載します。
