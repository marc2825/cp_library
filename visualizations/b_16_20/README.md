## 図の範囲と簡略化

全31項目に独立したモードがあります。modは101以下の素数、通常の係数は最大16項、観測は24項、集合関数は4変数まで、正方行列は4次までです。各モードは入力時に追加の形状・次数・零条件を検査します。入力係数は絶対値100万以下で正規化し、Numberの正確な整数範囲内で演算します。多項式剰余冪の指数は10進文字列でuint64まで、ビット操作にBigIntを使います。図の直接積はC++のNTT作業容量制約を再現しません。例えば法17のC++ FPS精度上限は8ですが、図ではより多い小入力を直接計算できます。

- Relaxed/Onlineは既知係数の寄与を直接表示し、予約ブロックのNTT処理やキャッシュは図にしません。Sparseもdenseな小配列へまとめ、係数漸化式を追います。Sparse powは小さい指数の繰り返し積です。
- ブロック積は各ブロック対の加算、tensorは座標とflat index、Middleは窓内積、Chirp-Zは等比点とHornerを表示。GCD/LCMとMin-Plusは全組の定義計算で、C++の変換・凸列mergeを再現しません。Min-Plusモードは凸列同士です。
- 合成はHorner法を表示し、C++のbaby-step/giant-stepと異なります。合成逆はNewtonの誤差・微分・補正を表示。積木は構築を表示し、評価はHornerを使用します。部分分数は重根ごとの局所Taylor係数と主部を表示します。
- 推定はBMを表示し第N項への延長は80項までの逐次計算。P-recursiveは30項まで、EGFは直接二項和、有理係数は係数漸化式、重み付き等比和は40項までの直接和です。C++の遠い項計算やuint64の高速性を図の処理時間から推測しないでください。
- SPS inv/log/expは高位変数の分割と部分集合積。SPS合成はHorner、集合分割は最小要素で重複除去、Subset Convolutionはranked-zeta・rank積・Möbiusを表示します。
- CSRは重複も保持する行境界と積、Black-BoxはKrylov列と剰余多項式の重み、Wiedemannは射影列とBMを表示。行列最小多項式はI,A,…のベクトル化による依存探索で、C++の各eᵢのKrylov依存のlcmとは独立な確認方法です。
- Low-RankはAを入力して初期逆を計算します。C++APIは既知のA^-1を受け取ります。核行列KとWoodbury補正、特異更新を表示します。Matrix TreeはLaplacianと余因子です。
