# 3.1〜3.6 A項目の操作できる解説

[index.html](index.html) をブラウザで直接開きます。32モードの入力・操作列をJSONで編集し、「入力を反映」から履歴を作り直します。「最初・戻る・次へ・最後・再生」で状態を追えます。[APIとC++検証](../../docs/a_priority/README.md) / [一次資料](../../docs/a_priority/references.md)。

各モードのサンプルが入力形式を示します。演算は区間和/アフィン変換、集合は数値の昇順、木上Moは頂点集合の例です。任意のC++コールバックを実行する画面ではありません。配列は原則16要素、操作40個、Grayは6bit、部分集合対はn<=5、順列はn<=10。FastSetは10000以下、商列挙は10000以下、二次元は8×8以下。入力と途中結果はJavaScriptの安全な整数の範囲に制限します。

- TreapとRBSTは木の形・部分木の個数・探索を示します。乱数は教材用32bit LCGで、C++のSplitMix64とは木の形が一致しません。RBSTは異なるキー数に比例した根選択を実行します。
- Lazy Reversible Treapは切出し・作用・反転後の**論理列**を表示します。C++の遅延タグ付きノード形状は再現しません。順序を反転してから区間を結び直す原理を示します。
- 部分永続DSUは過去時刻を配列スナップショットとして表示し、C++の更新時刻/サイズ履歴をそのまま保存する実装ではありません。完全永続DSUも版ごとの論理的な親配列を表示し、C++の永続配列の経路共有は描きません。
- 永続Stack/Queueは共有ノードと版を表示します。Queueの先頭は論理列にも表示し、祖先表を併記します。図中の版IDとC++のrootハンドル値は一致しません。
- 動的区間木と作用モノイドは再帰的な分割と遅延伝播を表示します。通常のDynamic Segtreeも説明上は一点代入を区間作用として表現します。作用モノイドの図は同じ疎な木を使い、C++の密なLazySegtreeと配置が異なります。
- 二次元BIT・座圧BIT・二次元Segtreeは、それぞれの内部セルと集約を表示します。図の座標は小さな非負整数格子で、C++の座圧版の任意座標値を制限します。Segtreeの図の更新操作addは、現在値に加算してsetへ渡す使用例です。
- DSTはsuffix/prefix、Offline RMQは単調スタックと親リンク、Rollback Moはsnapshot前の右部分と一時的な左追加、木上Moは往復列のtoggleとLCAの一時追加を表示します。

```sh
node verify/visualizations/a_priority_model_test.js
node verify/visualizations/a_priority_browser_test.mjs --browser /path/to/chromium
```

モデルは素朴配列・集合・全探索・BFSと比較します。ブラウザは全32モードの入力編集・履歴・再生・エラー回復・ローカルリンク・390px表示を検証します。
