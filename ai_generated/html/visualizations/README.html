インタラクティブ図解

図解一覧を開く — visualizations/index.html をブラウザで直接開きます。サーバー・ビルド・外部通信は不要です。 GitHub 上では HTML が表示されないため、手元に clone して開いてください。

  • 開き方の例：Windows（WSL）は explorer.exe "$(wslpath -w visualizations/index.html)"、macOS は open visualizations/index.html、Linux は xdg-open visualizations/index.html。
  • 一覧では分野別の目次、検索（日本語・英名・略称。ひらがな・全角も可）、A–Z 索引から各図解へ移動できます。index.html?q=segtree のように検索語を付けて開くこともできます。
  • 図解の「解説」「仕様・使い方」リンクは、Markdown を変換した html/ のページを開きます。元の .md は GitHub や VS Code で読むためのものです。
  • 一覧は entries.json から生成します。図解を追加・変更したら entries.json を編集し、make site で一覧と html/ を再生成、make check-site で最新か確認します。新しいページには <script defer src="../assets/doc-links.js"></script> を入れてください。
  • 図解 UI を作り直すときの共通仕様は DESIGN.md（見本）にあります。現状のページはまだ古い UI です。

  • Segtree
  • Lazy Segtree
  • Dual Segtree
  • 区間加算・区間和 BIT
  • 仕様・使用例・計算量・問題例

配列の初期化、任意の更新／問い合わせ、戻る／次へ／再生、おすすめの操作列に対応します。更新途中で新しい操作を実行した場合は、現在の操作を完了してから続けます。操作の開始・完了位置まで戻ると、その時点から履歴を作り直せます。

3.4 静的クエリ・単調構造・SWAG #

  • Sparse Table — 前計算と 2 区間の重なり。
  • Monotonic Stack — 左右の最近傍、厳密／同値を含む比較。
  • Monotonic Queue — 論理要素と候補列の違い。
  • Sliding Window Minimum — 期限切れと最左の argmin。
  • SWAG — 連結／和、2 スタックの移し替えと集約方向。
  • SWAG Deque（D-01） — 両端push/pop、半分ずつの再構築、連結／和、clear。
  • 仕様・usage・計算量・問題例。

配列・窓幅・優先する大小・厳密性・走査方向・集約を変更できます。ステップ処理、キューの任意 push/pop、問い合わせ、再生と履歴の分岐に対応します。キューの入力全体は説明用に表示し、C++ の単調キューが保持するのは候補のみです。移し替え途中の SWAG は、残る back の前半と front へ移した後半を並べて元の列を表示します。

3.5 標準コンテナ・座標圧縮・順位管理 #

  • set — 重複しない集合と前後検索。
  • multiset — 1 個の削除と全削除。
  • map — try_emplace、insert_or_assign、find、operator[]。
  • 座標圧縮 — ソート・同値の集約・境界位置。
  • 圧縮＋BIT — 頻度、累積順位、k 番目と前後検索。
  • API・usage・計算量・問題例。

初期要素・登録候補・昇降順を変更し、更新・削除・検索・再生・履歴の分岐を試せます。初期 map の値はキー×10 にしています。標準コンテナの図は論理的な並びと比較の概念であり、実装依存の木の形状を再現していません。数値の図解では安全な JavaScript 整数を使い、C++ の個数上限とは別に入力を制限します。

3.6 オフラインクエリ・二次元データ構造 #

  • Mo — 種類数、区間の伸縮、処理順の移動経路。
  • 並列二分探索 — 辺追加・初回連結、low/mid/high、毎ラウンドの reset。
  • Sweep Line — 点と走査線、y の圧縮・BIT、半開長方形の境界。
  • CDQ — 時刻分割、左更新 → 右問い合わせ、4 つの prefix 和、巻き戻し。
  • API・usage・計算量・問題例。

配列・ブロック幅・辺列・点・問い合わせ・操作列を編集できます。「条件を反映して実行」でバッチ全体から履歴を作り直し、戻る／次へ／再生で途中を追います。CDQ の時刻列は展開後のイベント順です。薄い点には未来の更新も含まれ、BIT に入るのは現在の分割で有効な左側の更新だけです。数値は図解用に ±100 万以内へ制限しています。

3.7 グラフ：基本探索・最短路・MST #

  • BFS / DFS — FIFO とスタック、行きがけ順・帰りがけ順。
  • 0-1 BFS / Dijkstra — deque と優先候補、緩和・古い候補。
  • Bellman–Ford / Warshall–Floyd — 負辺・負閉路の影響、全点対の行列。
  • トポロジカルソート / 閉路検出 — 入次数、3 色 DFS、自己ループ・多重辺。
  • Kruskal / Prim — 採用辺、成分、非連結な最小全域森。
  • 経路復元 — 親の頂点と辺 ID の逆走査。
  • API・usage・計算量・問題例。

頂点数・向き・辺・重み・始点・終点を変更できます。基本／非連結／負閉路／多重辺等の例を選び、入力から履歴を再生成します。全 11 モードで戻る／次へ／再生が可能です。最短路モードは「経路復元へ」で親の逆走査へ移動できます。DFS は全成分の dfs_forest、優先度付きキューは取り出し順の候補列で示します。C++ の各命令や内部ヒープ形状との一致は意図していません。

3.8 グラフ：連結成分・構造分解 #

  • SCC / 縮約 DAG — 正逆 2 回の DFS、成分順、内部辺と重複辺の除外。
  • Lowlink — ord/low と部分木サイズの伝播。
  • 橋 / 関節点 — < / ≤、根の特例、辺／頂点の仮削除。
  • 二部グラフ / 無向連結成分 — 全成分の探索・彩色・衝突。
  • API・usage・計算量・問題例。

7 モードで頂点数・辺・例を変更し、逆グラフへの移動、縮約辺の重複集約、再生・前後のステップを試せます。Lowlink／橋／関節点では辺 ID または頂点を仮に削除して成分数の増減を確認できます。そのとき ord/low は元のグラフの値、色分けと成分一覧は削除後です。二部グラフの衝突辺は説明用で、奇閉路全体の復元ではありません。

3.9 グラフ：フロー・マッチング・最適化 #

  • Dinic 最大流 — 残余容量・BFS の層・current arc・増加路と逆辺。
  • 最小カット復元 — 最大流後の到達範囲・頂点側・元辺 ID・容量の一致。
  • 二部最大マッチング — Hopcroft–Karp、左右の相手、最短の交互路と組み替え。
  • API・usage・計算量・問題例。

頂点数・左右の大きさ・有向辺・容量・始点／終点を編集し、入力から履歴を再生成します。前後のステップ・再生・次の増加路／交互路への移動、逆辺表示の切替に対応します。Dinic は流量上限を指定でき、残余辺で終点に届く間は最小カットを未確定と表示します。最小カットモードは常に流し切ります。マッチングの経路の橙／青は、反転前の追加／削除を表します。全てのスナップショットで流量保存とマッチングの妥当性を確認します。

3.10 グラフ：組合せ構造・数え上げ #

  • 三角形列挙 — 次数による向き・マーク・一意な列挙。
  • クリーク列挙 — 全て／極大のみ、P/X/pivot、空集合・打切り。
  • 最大クリーク / 最大独立集合 — 候補の交差・貪欲彩色の上界・枝刈り・補グラフ。
  • 彩色数 — 独立集合による厳密 DP・最小彩色の復元。
  • 行列木定理 — ラプラシアン・余因子・素数体上の行交換と消去。
  • API・usage・計算量・問題例。

6 モードで頂点数0〜8、辺を最大16本まで編集できます。列挙件数の上限、極大のみ、空集合を含むか、元グラフ／補グラフ、辺重み・素数mod・除く行列の頂点を変更できます。前後のステップ・再生・注目する状態への移動に対応します。DP は改善と確定を表示し、失敗した全ての候補は表示しません。消去後の行は元の頂点と一対一には対応せず、余因子内の行番号を使います。元のラプラシアンも別に表示します。剰余演算の乗算には BigInt を用います。

3.11 木アルゴリズム #

  • 部分木・深さ — 行きがけ／帰りがけ、親・サイズ・半開区間。
  • LCA — 祖先表、深さ調整、同時移動とパス上のk番目。
  • Euler Tour — preorder・往復の頂点列・辺ID列の違い。
  • 木の直径 — 非負重みの2回走査と復元。
  • 全方位木DP — 距離和、親側の寄与、prefix/suffixによる除外。
  • Binary Lifting — 任意の遷移・閉路・-1終端・uint64の回数。
  • Tree DP — 独立集合の白／黒の状態、帰りがけの集約。
  • API・usage・計算量・問題例。

7モードで根・頂点数0〜12・重み・始点／終点・k・遷移先を編集できます。形や重みの例、前後のステップ・再生・次の段階への移動に対応します。全方位木DPでは各隣接先の寄与と累積表を並べ、どの子を除いたかを表示します。図解のDPは距離和／独立集合の例で、C++の任意のコールバックの実行画面ではありません。Liftingの表は入力kに必要な段数のみを表示します。木のモードは森にも対応し、直径だけ連結・非負重みを要求します。

3.12 DP・最適化 #

  • LIS / LCS / 編集距離 — 二分探索、接頭辞の表、解の復元。
  • 0-1 / 完全 / 個数制限 — 更新の向き、剰余類の単調キュー。
  • Bitset Knapsack — シフトとOR、64ビット語、最終語の余白。
  • 区間DP / 桁DP / 部分集合DP — 分割、tight/started、巡回路・部分集合列挙・集合変換。
  • Largest Rectangle / 二値グリッド — 左端を引き継ぐ単調スタックと行ごとの高さ。
  • API・usage・計算量・問題例。

12モードで入力・狭義／広義・昇降順、容量・価値・個数、桁和の法・0を含むか、欠辺と始点、障害物を編集できます。部分集合では4種類の操作を選べます。空・同値・負値・重さ0・64ビット境界等の例、前後のステップ・再生・次の段階への移動に対応します。図解の区間DPは隣接結合、桁DPは桁和の例です。C++の任意のコールバックは実行しません。BitsetはBigIntで同じ集合演算を行い、C++の各機械語命令は再現しません。

3.13 数論：基本整数演算 #

  • GCD・LCM — 余りを小さくする互除法と、LCMの整数範囲を確かめます。
  • 拡張Euclid — 各余りの係数を更新し、Bézoutの恒等式を保ちます。
  • mod累乗 — 指数をビットに分け、積と二乗を追います。
  • mod逆元 — GCDが1のときだけ、係数を逆元へ正規化します。
  • 素数篩 — 素数の平方から倍数を消し、候補を絞ります。
  • SPF・最小素因数 — 合成数を一度ずつ生成し、表をたどって分解します。
  • 素因数分解 — 試し割りで素因数を取り出し、残る素数を見つけます。
  • 約数列挙 — 小さい約数と大きい約数を対で集め、昇順につなぎます。
  • API・usage・計算量・問題例。

8モードで負数・整数極値・指数・法・篩の上限・分解する数を変更できます。0・1・逆元なし・LCM超過・平方等の例、前後のステップ・再生・次の段階への移動に対応します。計算はBigIntで行い、Euclidの係数・累乗のビット・篩の除去・SPFの生成と分解経路・約数の2列を表示します。図解の上限は篩80・試し割り10,000です。余り0の係数もBigIntで表示しますが、C++はその不要な計算を省きます。mod乗算の各加算は再現しません。

3.14 数論：乗法的関数・高度な整数問題 #

  • 約数ゼータ変換 — 素数の冪に沿って、約数の値を小さい方から集めます。
  • 約数メビウス変換 — 加えた順序を逆にたどり、約数和から元の値へ戻します。
  • 倍数ゼータ変換 — 大きい添字から、倍数の値を小さい方へ伝えます。
  • 倍数メビウス変換 — 倍数の集計から、ちょうどの値へ逆変換します。
  • Dirichlet Convolution — 添字の積i*jへ係数の積を加え、約数ごとに集計します。
  • GCD Convolution — 倍数ゼータ・要素積・逆変換で、GCDごとの和を作ります。
  • LCM Convolution — 約数ゼータ・要素積・逆変換で、LCMごとの和を作ります。
  • API・usage・計算量・問題例。

7モードで2列の係数・整数／mod12／998244353／1・添字0・注目する添字を変更できます。素数の冪、負の値、出力の切り捨てと0拡張、64ビット境界、正の範囲が空の例を用意しています。各更新、素数の区切り、GCD/LCMの3段階を戻る／次へ／再生で追えます。元の入力から定義通りに集計した項と、作業中の値・履歴を併記します。BigIntで計算し、C++標準整数の超過例外は再現しません。配列は正の添字12個までです。
