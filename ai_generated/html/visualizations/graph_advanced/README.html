グラフの残り15項目の図解

操作画面 / API・検証 / 一次資料。JSON編集、再生、前後移動、SVG対象表示と状態表を備えます。外部通信・ビルド不要です。

全般にn<=8、辺数<=16、整数値−100〜100の教材入力。rankは左右<=5/14辺、Eulerは10辺、b-flowは容量−3〜4/組合せ10万以下、数え上げはn<=12、動的操作は30個以下。空グラフは数え上げのみ表示対象とし、C++の空入力対応とは異なります。

モード 教材モデル
G-16 Cost Scaling Min-Cost b-Flow 容量内の流量全列挙と保存則・費用。epsilonの操作列は再現しない。
G-20 少種類重みの最短路 C++と同じ重み別FIFOで距離と候補列を表示。
G-21 Shortest Nonzero Path 有限巡回加法群だけを単純パス全探索。C++は任意群のFastSUP。
G-22 Minimum Diameter Spanning Tree 全域木の辺集合を列挙し直径を比較。C++は連続中心。
G-23 SPQR Tree（分離対探索版） 分離対とS/P/Rの分割・併合を表示。
G-24 一般グラフの木幅分解 全消去順序で厳密幅を求め、fillとbagを表示。C++はsubset DP。
G-25 Cographの標準形 union/joinの構造文字列を下から組み立てる。
G-26 一般グラフ最大重みMatching 全matchingの重みを比較。C++のBlossom回転は再現しない。
G-27 Rank-Maximal Matching 全matchingの順位profileを比較。C++は多倍長Hungarian。
G-28 動的単位容量Max Flow 更新後の全カットと最大流値。C++は残余フローを修復。
G-29 ラベル付き連結グラフ数 BigIntによる成分サイズの漸化式。
G-30 強連結有向グラフ数 BigIntによるWright漸化式。
G-31 Euler閉路数（BEST定理） 辺IDのEuler列をDFS全列挙。C++はBESTと行列式。
G-32 一般グラフの厳密同型判定 頂点置換の全探索。C++は個別化と色精緻化。
G-33 二端子直並列グラフ分解 series/parallel縮約の式ノードを表示。
