Contour Query

カテゴリ索引 / B項目一覧 / 操作できる図解 / 実装 / 一次資料と設計

重心祖先ごとの距離BITと枝別BITを持ち、指定頂点から距離帯に入る頂点だけの寄与を包除で集計します。

usage #

#include <iostream>
#include "tree/contour_query.hpp"
int main() {
    cp::Graph<long long> g(3); g.add_edge(0,1,2); g.add_edge(1,2,3);
    cp::ContourQuery<> q(g); q.add(0,5); q.add(2,7);
    std::cout << q.sum(1,1,2) << '\n';
}

出力:

12

API・使用条件 #

ContourQuery<T>(g)のadd(v,x),set(v,x),get(v),sum(v,l,r)。ContourAddPointGet<T>(g)のadd(v,l,r,x),get(v)。無向森、重み無視、距離は辺数、半開区間[l,r)。Tは可換加法群。

頂点・辺IDは0始まり。グラフを受ける関数は構築時点の入力に対する計算です。重みや値の型は特記した制約に従います。

仕組みと境界 #

点加算/距離帯和と距離帯加算/点取得の両方向を提供します。同じ枝にいる対を引いて二重計数を防ぎます。l>=rは空、負の距離・LLONG_MIN/MAXの境界も安全にclampします。異なる成分は寄与しません。初期値は全0。

計算量 #

構築O(V log(V+1))、更新・検索O(log²(V+1))、領域O(V log(V+1))。 Vは頂点数。T の加減算をO(1)として数えています。

使用する問題・検証 #

想定問題: 一点加算と「v からの距離が [l,r) の頂点の和」、またはその逆の距離帯加算と一点取得（Vertex Add Range Contour Sum on Tree は ContourQuery、Vertex Get Range Contour Add on Tree は ContourAddPointGet と初期値で解けます）。 実行できる小問題。

検証では、150個の森で、点加算後の sum(u,l,r) と距離帯加算後の get を、l,r∈[−4,n+4) について全点対 BFS と照合し、LLONG_MIN/LLONG_MAX の区間でも成分和と一致することを確認します。上の使用例は実際にコンパイル・実行し、文書中のコードとの一致も検査します。
