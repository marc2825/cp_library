対象ファイル：basic_utility/static_modint.hpp

固定法modint

StaticModInt<Mod>（別名static_modint<Mod>）はコンパイル時の32bit法による整数環です。ModInt998244353・ModInt1000000007も用意します。関連する検証用型やparser内部型を置換せず、公開部品として独立させました。

使用例 #

#include <iostream>
#include "basic_utility/static_modint.hpp"
int main() {
    using Mint = cp::StaticModInt<12>;
    std::cout << Mint(-5) << " " << Mint(5).inv() << " " << Mint(6).try_inv().has_value() << "\n";
}

出力:

7 5 0

APIと使用条件 #

Mod は 1 <= Mod <= UINT32_MAX。加減算の中間値は64bit、乗算は64bitの積を剰余します。合成数や 2^31 以上の法も利用できます。型の法が固定なので同じ型の値は常に組み合わせられます。

共通modint API #

mod() は法、val() は [0,mod) の代表元。既定値は0です。bool以外の組み込み整数（符号付き／なし128bitを含む）を正規化して構築できます。整数極小値も受け付けます。

四則演算・複合代入・単項正負・前置／後置++/--・==/!=、整数との混合演算に対応します。pow(e) は 0 <= e <= UINT64_MAX。負の指数はinvalid_argument、上限超過はout_of_range。0^0=1 mod mとします。

try_inv() は optional<Mint> を返し、逆元がなければnullopt。inv()と逆元のない値による除算はdomain_errorです。素数法は要求せず、gcd(x,m)=1を確認します。法1では代表元0を逆元とし、すべての演算は0を返します。

<<は代表元、>>は符号付き10進整数トークンを扱います。桁数に上限はなく逐次剰余を計算します。不正なトークンはfailbitを立て、対象値を変更しません。比較は同じ型の代表元の一致です。異なる法／IDの型同士の演算・暗黙変換は提供しません。rawなど内部表現を直接作るAPIはありません。

共通の逆元計算には既存のmod_inverseを使います。整数演算を単位時間とすれば加減乗算・比較はO(1)、冪はO(log(e+1))、逆元・除算はO(log m)、入力は桁数Lに対してO(L)時間／トークン保持O(L)領域です。値1つの領域はO(1)。
