3.1 基本ユーティリティ・探索

C++17、namespace cp。共通入口は basic_utility/all.hpp。各ヘッダを単独でincludeできます。

V-05：デバッグ出力を追加しました。コンテナ・tuple・任意型の整形と、提出時に引数評価ごと消すCP_DEBUG。図解。make verify-development-runtime。

共通基盤 F-11（2026-10-19） #

多倍長整数BigInt / 図解。Boostヘッダが必要な符号付き任意精度整数です。加減乗除・剰余・GCD・LCM、厳密な10進／16進変換、128bitまでの範囲検査付き変換を扱います。入力1万桁・積2万桁まで独立比較。make verify-big-integer。

共通基盤 F-08（2026-10-19） #

seed付き複合キーハッシュ / Open Addressing Hash Map / 操作できる図解。整数・pair・tuple・列のhash、衝突・削除・再構築、固定seedでの再現に対応します。検証範囲。make verify-foundation-structures。
