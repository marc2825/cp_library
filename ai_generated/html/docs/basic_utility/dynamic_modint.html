実行時法modint

DynamicModInt<Id=0>（別名dynamic_modint<Id>）は実行時に法を変更できる型です。乗算にはBarrett Reductionを共有します。

使用例 #

#include <iostream>
#include "basic_utility/dynamic_modint.hpp"
int main() {
    using A = cp::DynamicModInt<0>;
    using B = cp::DynamicModInt<1>;
    A::set_mod(12); B::set_mod(7);
    A a = 5;
    std::cout << a.pow(3) << " " << B(5).pow(3) << "\n";
    A::set_mod(11);
    try { std::cout << a.val(); }
    catch (const std::logic_error&) { std::cout << "stale\n"; }
}

出力:

5 6
stale

APIと使用条件 #

set_mod(uint32_t m) は 1 <= m <= UINT32_MAX。初期法は998244353です。IDごとに法と世代番号を共有し、異なるIDは独立です。

set_modは同じ法を再設定しても既存値をすべて無効化します。 古い値のval()・比較・算術・冪・逆元を使うとlogic_error。コピーは世代も保持し、有効化しません。x = Mint(整数)で新しい値を代入できます。法の設定は値の構築より前に行ってください。無効な法はinvalid_argument、世代番号上限はoverflow_errorで、失敗時は現在の法・既存値を保持します。

法と世代はC++17のinline staticで翻訳単位間でも共有します。同一IDのset_modと他操作の並行実行には外部同期が必要です。世代を各値に持つため固定法版よりサイズと検査の負担があります。set_mod・世代検査はO(1)です。

共通modint API #

mod() は法、val() は [0,mod) の代表元。既定値は0です。bool以外の組み込み整数（符号付き／なし128bitを含む）を正規化して構築できます。整数極小値も受け付けます。

四則演算・複合代入・単項正負・前置／後置++/--・==/!=、整数との混合演算に対応します。pow(e) は 0 <= e <= UINT64_MAX。負の指数はinvalid_argument、上限超過はout_of_range。0^0=1 mod mとします。

try_inv() は optional<Mint> を返し、逆元がなければnullopt。inv()と逆元のない値による除算はdomain_errorです。素数法は要求せず、gcd(x,m)=1を確認します。法1では代表元0を逆元とし、すべての演算は0を返します。

<<は代表元、>>は符号付き10進整数トークンを扱います。桁数に上限はなく逐次剰余を計算します。不正なトークンはfailbitを立て、対象値を変更しません。比較は同じ型の代表元の一致です。異なる法／IDの型同士の演算・暗黙変換は提供しません。rawなど内部表現を直接作るAPIはありません。

共通の逆元計算には既存のmod_inverseを使います。整数演算を単位時間とすれば加減乗算・比較はO(1)、冪はO(log(e+1))、逆元・除算はO(log m)、入力は桁数Lに対してO(L)時間／トークン保持O(L)領域です。値1つの領域はO(1)。
