usage #

#include <iostream>
#include "union_find/rollback_disjoint_set_union.hpp"
int main() {
    cp::RollbackDisjointSetUnion d(3); auto saved = d.snapshot();
    d.merge(0, 1); d.merge(1, 2); std::cout << d.component_size(0) << ' ';
    d.rollback(saved); std::cout << d.component_count() << '\n';
}

実行できる使用例。C++17、namespace cp。ライブラリルートをincludeパスに追加してください。出力は 3 3 です。

API・使用条件 #

RollbackDisjointSetUnion(n)、size()（頂点数。DisjointSetUnion::size(v)と違い引数なし）、leader/same/component_size/component_count、merge(u,v)->bool、merge(u,v,callback)（併合の直前にcallback(残る根,吸収される根)を呼ぶ）、snapshot()->size_t、undo()、rollback(snapshot)。merge失敗も履歴を1個積むため、undoは直前のmerge呼出しを取り消します。snapshotは同一オブジェクトの現在の履歴の祖先に限ります。空履歴のundo・将来や破棄した枝のsnapshot・不正添字は契約外。

計算量・原理 #

leader/same/mergeはO(log n)、undoはO(1)、rollbackは取り消す回数に比例。格納O(n+履歴長)。

サイズの小さい木を大きい木へつなぎ、変更した根の対だけを保存します。経路圧縮を行わず、巻戻し時に親とサイズと成分数を復元します。
