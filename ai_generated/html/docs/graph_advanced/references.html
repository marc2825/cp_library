取り込みとライセンス #

G-26だけ外部C++ coreを取り込み、その他はアルゴリズムの定義と既存部品に基づく独立実装です。

graph_flow/detail/weighted_blossom.hpp はBoost Graph commit 54a94911e68dccf5812b32d018566566700499f3（boost-1.89.0）の maximum_weighted_matching_context を保持し、公開wrapper・brute-force・入力検査ヘルパーを除いてnamespaceを cp::weighted_blossom_detail に隔離しています。上流の著作権表示（Yi Ji / Joris van Rantwijk）とBoost Software License 1.0本文を保存。出典台帳に元ファイルhash、固定版、変更点とローカルhashがあります。NDEBUG時の警告対策としてassert専用ループ変数にmaybe_unusedを付け、coreのアルゴリズムは変更していません。

環境のBoost 1.74の旧matchingは試験でblossomの循環所有によるLSanリークを検出したため採用せず、所有権を整理した固定版へ置き換えました。基本グラフ型はシステムBoost 1.74と組み合わせて検証します。BigIntは既存のBoost.Multiprecision依存を共有します。追加のリンクライブラリは不要です。

少種類重みのFIFO、消去集合の木幅DP、cographのunion/join文字列、単位容量フロー修復、連結成分の数え上げ、同型の個別化と精緻化、二端子SP縮約は、各ページに証明の要点と計算量を記載しています。図解は独立の教材モデルで、C++の高速coreの実行トレースではありません。
