2026-10-19確認。これらはAPIと挙動の確認資料で、実装はこのリポジトリ向けに作成しています。

  • GCC Variadic Macros: 引数文字列化と可変引数。C++17で値1個以上を受け取るマクロを使用し、無効時は引数を置換結果へ含めません。
  • Python selectors: nonblocking I/Oのread/write監視。POSIXではpipeを扱い、Windowsではpipeを監視できない制約。
  • Python subprocess: argv、cwd、process session、waitとtimeout。前回の資料と共通。
  • Python concurrent.futures: ThreadPoolExecutorによる外部プログラムの並列管理、保留中futureの取消。

既存のstress testerのプロセス管理を共有部品へ切り出して使用します。C++の128bit判定は既存の整数traitsを共有します。AHCのスコア方式を一律に仮定せず、外部scorerの生スコアと比較方向を明示的に指定します。
