取り込みと変更 #

共通coreは上記Lazy Top Treeをadaptしたものです。new/deleteによる所有権の曖昧さをなくすため、頂点とrakeノードをunique_ptrで所有し、削除したrakeノードはfree listで再利用します。splay前に祖先から順にlazyをpushし、非可換な作用の合成順を明示しました。公開インターフェースは0始まりの頂点番号・bool/optional・値返却・move可能/コピー不可へ変更し、非lazy Specも同じcoreで使います。元コードの大きな雛形コメントは含めません。

Unlicense本文を保持し、台帳に取得commit・元のSHA-256・変更説明・ローカルSHA-256を登録します。

中心と根変更区間は既存の tree/diameter.hpp、RootedTree、HLDを共有する追加実装です。静的Top Treeを動的版に置換せず、それぞれの計算量と用途を維持します。独立集合・距離和のSpec、ActedMonoidアダプタ、公開ラッパーは本API向けに作成しています。

ジャッジラッパーのPROBLEMは対応する入出力形式を示すもので、オンラインACの主張ではありません。
