対象ファイル：number_theory_convolution/multiple_zeta_transform.hpp

倍数ゼータ変換

F(n)=\sum_{k\ge1,\,kn\le N}f(kn)

素数pごとに f[k]+=f[k*p] をkの大きい順で行います。pの高い冪から低い冪へ値を渡すことで、上限以下の倍数を一度ずつ集めます。

usage #

#include <iostream>
#include <vector>
#include "number_theory_convolution/multiple_zeta_transform.hpp"
int main() {
    std::vector<long long> f{0, 1, 2, 3, 4, 5, 6};
    cp::multiple_zeta_transform(f);
    for (std::size_t i = 1; i < f.size(); ++i) std::cout << f[i] << ' ';
    std::cout << '\n';
}

動く使用例。ルートディレクトリをincludeパスへ通します。

API・使用条件 #

multiple_zeta_transform(std::vector<T>& f) -> void

  • 正の添字1〜Nだけを変換します。Nは f.size()-1、添字0は読み書きせず保持します。
  • 空ベクトルは何もしません。長さ1（添字0だけ）も保持します。
  • in-placeで、逆変換は入力が特定のゼータ変換の結果であることを要求しません。任意の列へ定義式を適用します。

係数型：加算が結合的・可換で、T& operator+=(const T&) が使えること。減算・乗算は不要です。

上限Nはintに収まる必要があり、超過は length_error。係数演算の法はアルゴリズム側で固定しません。標準整数型（boolを除く）は全ての途中の加算・減算・乗算が表現可能である必要があり、超過は overflow_error です。符号なし整数の折り返しも行いません。独自型の算術条件は利用側が管理します。変換中の例外では、それ以前の更新が残るため、同じ配列で再開しないでください。

計算量・注意点 #

素数篩を含めO(N log log(N+2))時間。追加空間は素数篩O(N)ビットと素数列O(π(N))語です。 係数の演算・コピーをO(1)とした評価です。大きい型の場合はその費用が掛かります。number_theory_basic/prime_sieve.hppを明示的に再利用しています。

素数ごとの更新には走査順の意味があります。全ての倍数を同じ向きで加えるO(N log N)の直接集計とは処理順が異なります。
