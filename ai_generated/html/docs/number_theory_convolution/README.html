3.14 数論：乗法的関数・高度な整数問題

今回のA項目は、正整数の添字を持つ算術関数の変換と畳み込みです。入力の係数列が乗法的関数である必要はありません。C++17・namespace cp、all.hppからまとめて使えます。

欲しい値 実装・API・usage 時間
約数からの集計 Σ_{d∣n} f[d] 約数ゼータ変換 O(N log log N)
約数和から元の値へ 約数メビウス変換 O(N log log N)
倍数からの集計 Σ_{n∣m} f[m] 倍数ゼータ変換 O(N log log N)
倍数和から元の値へ 倍数メビウス変換 O(N log log N)
積ij=nに集計 Dirichlet Convolution O(N log N)
GCD(i,j)=nに集計 GCD Convolution O(N log log N)
LCM(i,j)=nに集計 LCM Convolution O(N log log N)

操作できる図解：7モード / 動く使用例 / 一次資料・設計判断

正整数1〜Nに対して長さN+1の vector<T> を用意します。変換はin-placeで添字0を保持し、畳み込みは入力の添字0を無視して結果の0をゼロにします。空も扱えます。畳み込みの出力長は両入力の最大長、短い入力は0で補い、DirichletとLCMで上限を超えた組は捨てます。GCDは大きい入力の添字が小さい結果にも寄与するため、入力を先に切らないでください。

係数型は整数やmod型等を使います。割り算・逆元・素数法の条件はありません。乗算順は a[i]*b[j] で、加算が可換な群・乗算が分配的なら行列等も扱えます。zetaだけなら加算だけ、mobiusだけなら減算だけのAPI条件です。標準整数の全ての途中値は表現可能である必要があり、超過は例外です。符号なしの折り返しも行いません。独自型の算術条件は利用者が管理します。

素数列は 3.13のPrimeSieve を再利用します。既存の数論・部分集合の変換とは別のAPIです。整数のμやφの表を構築する機能は今回の項目には含めず、φの例は約数メビウス変換で計算します。
