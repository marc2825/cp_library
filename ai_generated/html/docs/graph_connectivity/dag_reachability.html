DAG Reachability

カテゴリ索引 / B項目一覧 / 操作できる図解 / 実装 / 一次資料と設計

逆topological順でpacked bitsetを併合する全対版と、64問い合わせずつ始点bitを伝える省領域バッチ版を用意します。

usage #

#include <iostream>
#include "graph_connectivity/dag_reachability.hpp"
int main() {
    cp::Graph<long long> g(3,cp::GraphKind::Directed);
    g.add_edge(0,1); g.add_edge(1,2);
    cp::DAGReachability r(g); std::cout << r.reachable(0,2) << ' ' << r.reachable(2,0) << '\n';
}

出力:

1 0

API・使用条件 #

DAGReachability(g).reachable(u,v)。dag_reachability(g,vector<pair<int,int>> queries) → vector。有向DAG以外はinvalid_argument。長さ0の道を含みu=uはtrue。

頂点・辺IDは0始まり。グラフを受ける関数は構築時点の入力に対する計算です。重みや値の型は特記した制約に従います。

仕組みと境界 #

到達集合を保持する方向と、問い合わせの始点bitを伝える方向は逆です。空入力・空問い合わせ可。重みは無視します。グラフの更新は反映しません。

計算量 #

全対構築O((V+E) ceil(V/64))、領域O(V ceil(V/64))、query O(1)。バッチO((V+E) ceil(Q/64)+Q)、領域O(V+E+Q)。 Vは頂点数、Eは論理辺数。

使用する問題・検証 #

想定問題: DAG 上の多数の到達可能性クエリ（全対版は V が数万まで、バッチ版は領域 O(V+E+Q) で大きな V にも使えます）。 実行できる小問題。

検証では、n≤34 のランダムな DAG 300個で、それぞれ180問を BFS と比較し（両方の API）、閉路を含む入力で invalid_argument になることも確認します。上の使用例は実際にコンパイル・実行し、文書中のコードとの一致も検査します。
