最適化O全8項目・ゲームB-20

組合せ最適化 / ゲーム理論 / 9モードの図解 / 一次資料

O-01〜O-04・O-20〜O-23の8項目とB-20を整備しました。O-05〜O-19、B-01〜B-19の行はありません。C++17、namespace cp。Oはcombinatorial_optimization/all.hpp、Bはgame_theory/all.hppへ追加しています。

ID API・説明 主な用途
O-01 二段階Simplex・線形計画 資源配分、混合戦略のLP、連続緩和と双対証明。
O-02 固定1〜3次元の厳密LP 2D/3Dの半空間制約、退化した領域上の線形目的。
O-03 Matroid Union・Partition 辺の複数森林への分配、異なる独立条件を持つ担当先への割当。
O-04 分数計画・Dinkelbach・比率二分 利益/費用や総得点/総量の比率を最適化する問題。
O-20 重み付きマトロイド交差 色制約付き森林、容量付き二部割当、重みと要素数の両方を調べる問題。
O-21 Base Polyhedron・Lovász拡張 劣モジュラ関数の基の生成、Lovász拡張、凸最適化の線形oracle。
O-22 劣モジュラ最適化 カットにモジュラ項を足した集合関数の最小化、被覆の個数制限付き近似最大化。
O-23 有限上下限付き整数線形計画 小規模な整数資源配分、有限範囲の線形制約、LP緩和で枝を削れる探索。
B-20 Q(ω)の超現実数・無限小 無限大・無限小を含む数の比較、数としてのゲーム値の和・差、記号的な漸近順序。

共通仕様・共有部分 #

入力配列は保持し、返す解は独立した値です。次元・負のサイズ・非有限入力などはinvalid_argument、明示上限はlength_error、0除算はdomain_error。oracleからの例外は伝播します。マトロイド公理や劣モジュラ性は呼び出し側の条件で、全公理の検査はしません。oracleへ渡す要素は0始まり・重複なしで、順序に依存してはいけません。

BigRationalを使う厳密LP・低次元LP・基多面体・劣モジュラ最小化・整数計画・Q(ω)にはBoostヘッダが必要です。Simplexは浮動型も選べますが、epsilonによる分類を厳密証明とは扱いません。重み付き交差は既存の検査付き128bit、分数計画はYのlong double許容誤差を使います。

既存のGraphicMatroid・PartitionMatroid・Gauss–Jordan・BigRational・PartizanOutcomeを共有します。有理多項式の共通処理はbasic_utility/detail/rational_polynomial.hppへ抽出し、YのSturm実根分離とQ(ω)が同じ除算・GCDを使います。

低次元LPの基底列挙は固定次元dで制約数mのO(m^(d+1))規模です。Simplex、cutting-planeによる一般劣モジュラ最小化、整数計画には指数時間の最悪ケースがあります。予算終了・候補解・証明済みの最適解を区別するAPIです。回数予算は任意精度演算のbit成長やcallbackの実行時間を制限しません。
