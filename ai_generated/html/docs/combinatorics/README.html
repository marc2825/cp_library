3.15 組合せ論・数え上げ

C++17・namespace cp。all.hppでまとめて、個別のヘッダで必要な機能だけを使えます。

求めたい数 実装・説明 主な条件
階乗・逆階乗 FactorialTable / factorials 逆階乗には上限の階乗が法と互いに素であることが必要
二項係数 binomial / PascalBinomial 高速版と、合成数法にも対応するO(N²)表
順列・組合せ permutations / combinations nPkは順序付き、nCkは順序を無視
Catalan数 catalan 2nまで前計算。二項係数の差で計算
重複組合せ multiset_combination n種類からk個。H(0,0)=1、H(0,k>0)=0
包除原理 union / complement 選んだ集合の共通部分を返すコールバック

操作できる図解：7モード / 動く使用例 / 一次資料・設計判断

通常は FactorialTable(max_n,modulus) を1回作り、binomial(table,n,k) 等を繰り返し問い合わせます。既定の法は998244353。素数法でも上限が法以上になると階乗の逆元が存在しなくなります。構築時に検出し、domain_errorで拒否します。小さい上限で任意の正の法を使う場合は PascalBinomial。階乗だけなら factorials 関数は逆元を要求しません。

法1は結果を全て0にする規約です。高速版の積は3.13の安全なmod乗算・逆元を再利用し、64ビットの正の法まで対応します。一般の大きい法の問い合わせはO(log m)、m<=2^32ならO(1)です。通常の整数の割り算でmod下の除算を置き換えないでください。

包除原理は和集合と、その補集合を分けています。補集合のmask=0は全体集合です。標準整数では途中の範囲超過を検出します。途中で負になる場合があるため、符号付き整数かmod型を使うのが基本です。部分集合の列挙は指数時間で、63集合という値はビット表現上の上限です。

旧組合せ計算はリポジトリ直下の depricated/Combination/ に保存しています。公開フィールドや旧関数の別名へは置換していません。巨大nのLucas・任意法の高速二項係数や、具体的な順列の列挙は今回のAPIに含めません。

追加A項目（2026-10-17） #

  • Stirling数（第1種・第2種） — 順列のcycle数と集合分割のブロック数を数える三角表を構築します。
  • Bell数 — N要素の集合を、順序のない非空ブロックへ分ける方法を数えます。
  • 整数の分割数 — 正整数の和による整数分割を、和の順序を区別せずに数えます。
  • Montmort数 / Derangements — 固定点が一つもない順列の個数を求めます。
  • Burnsideの補題 — 群作用で同一視される対象の数を、固定点数の平均から求めます。
  • Pólya Enumeration / Cycle Index — 群の全置換からcycle indexを構築し、色数や重みを代入して軌道を数えます。

追加分の契約・検証範囲 / 18モードの図解。追加分は python3 verify/run_math_a.py / --sanitize で検証します。既存APIとカテゴリ検証は保持します。
