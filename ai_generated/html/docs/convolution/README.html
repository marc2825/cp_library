3.16 畳み込み・高速変換

C++17・namespace cp。all.hppでまとめて、個別ヘッダでも使えます。

用途 実装・説明 条件・結果
有限体で変換 ntt / ntt_max_size 既定998244353、素数と原始根を検査。2冪長
通常のmod畳み込み convolution 整数入力を正規化し、NTTで正確に計算
通常の整数畳み込み convolution_ll 3法CRT、64ビット整数。絶対値の十分条件を検査
実数・複素数のFFT fft / fft_real float/double/long double、全スペクトル、近似値
実数・複素数の畳み込み convolution_fft 自動0埋め、実数または複素数の近似値

操作できる図解：6モード / 使用例 / 一次資料・設計判断

通常の畳み込みは c[k]=Σ_(i+j=k) a[i]b[j] で、係数は定数項から昇冪順です。空を含む場合は空、それ以外は|a|+|b|−1個を返し、末尾の0も残します。畳み込み関数は自動0埋め、変換関数は2冪の長さを利用者が用意します。

NTTとFFTはどちらも順変換に正の指数、逆変換に負の指数と1/nを使い、自然順→自然順です。FFTを他ライブラリと比較するときは符号と正規化を確認してください。

mod版はNTTに適した素数が対象です。任意法への高速CRT版はconvolution_modを使います。整数版は保守的な絶対値上限を満たす場合に正確な値を返し、打ち消しで上限を超える入力も明示的に拒否します。実数・複素数版は近似値なので、整数の正確さが必要な場合と使い分けます。

3.14の約数・倍数による畳み込みとは添字の集計規則が異なり、別カテゴリです。既存カテゴリと3.15の変更は保持しています。標準C++17のみで、外部ライブラリや__int128に依存しません。

検証 #

python3 verify/run_convolution.py
python3 verify/run_convolution.py --sanitize
node verify/visualizations/convolution_model_test.js
node verify/visualizations/convolution_browser_test.mjs --browser /path/to/chromium

make verify-convolution、全図解モデルはmake verify-visualizations。Python/npmの追加パッケージは不要です。

7ヘッダの単独／逆順／混在includeと複数翻訳単位、5使用例、5ジャッジ形式・360ケースを検証します。14,641組の三値配列、8組の法／根、直接の有限体DFT・複素DFT、400ランダム整数積・300複素数積、Python任意精度858組・2,838出力と比較します。空・1要素・2冪境界・符号付き／符号なし極値・CRTの符号・保守的上限・NaN/Inf・非有限の途中値も含みます。

2^20点NTT、10万×10万の整数／mod積、65,537×65,537の実数FFTも確認します。doubleの大きい実数例では全出力の絶対誤差を測定しますが、この試験の誤差を一般の保証値とはしません。

検証入口：通常／ASan・UBSan、debug/release。オンラインACは未確認です。
