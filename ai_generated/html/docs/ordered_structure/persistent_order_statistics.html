Persistent Order Statistics

カテゴリ索引 / 図解 / 実装 / 一次資料・設計判断

usage #

#include <iostream>
#include "ordered_structure/persistent_order_statistics.hpp"
int main() {
    cp::PersistentOrderStatistics<int> s({5, 1, 4, 1, 3});
    std::cout << *s.kth_smallest(1, 5, 2) << ' ' << s.count_less(0, 5, 4) << '\n';
}

実行できる使用例。C++17、namespace cp。ライブラリルートをincludeパスに追加してください。

API・使用条件 #

PersistentOrderStatistics<T>(vector<T>)、size()、kth_smallest(l,r,k)->optional<T>（0始まり）、count_less(l,r,x)、range_freq(l,r,low,high)。静的な列の各prefixを自動で永続化し、任意区間に問い合わせます。k範囲外はnullopt、空入力可。<とコピーが必要。更新版を自分で管理する用途は Persistent Segment Tree を使います。

計算量・原理 #

構築O(n log(n+1))、検索O(log(σ+1))、格納O(n log(σ+1)+σ)。σは異なる値の数。

各prefixの値の頻度を永続木に保存し、prefix rの頻度からprefix lを引いて[l,r)の頻度を得ます。左の子の頻度差とkを比較して降ります。一般モノイドの2つのprodを引いてk番目を求めるAPIではありません。

使用する問題・検証 #

関連問題。関連問題は用途の例であり、このAPIだけでそのまま全て解けるという意味ではありません。特に動的連結性の関連問題は追加の成分和が必要です。

追加分の検証入口で、素朴解との比較、空・重複・境界、非可換集約、履歴分岐、繰返し実行、20万要素の主要構造を検査します。実際の範囲は検証一覧を参照。オンライン提出のACは未確認です。
