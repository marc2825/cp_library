Farthest Pair

点群の凸包を求め、既存のRotating Calipersで最遠点対を返します。

カテゴリ索引 / 28項目の一覧 / 操作できる図解 / 一次資料と設計判断

API・使用条件 #

geometry::exact::farthest_pair(points) / floating::farthest_pair(points)→optional。元の入力添字とsquared_distance。

空はnullopt、一点や同一点群は距離0。重複座標は最初の元添字を選びます。同じ最大距離の複数の点対の辞書順最小は保証しません。浮動版の凸包・距離にはEPSを入れません。既存直径APIを共有。

usage #

#include <iostream>
#include <vector>
#include "../../computational_geometry/farthest_pair.hpp"

int main() {
    auto pair = cp::geometry::exact::farthest_pair({{0, 0}, {3, 4}, {1, 1}});
    std::cout << static_cast<long long>(pair->squared_distance) << "\n";
}

出力:

25

コンパイルして動く使用例。

計算量 #

O(N log N)時間、O(N)領域。
