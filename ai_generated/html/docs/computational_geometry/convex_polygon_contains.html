Convex Polygon Contains

カテゴリ・共通仕様 / 操作できる図解 / 一次資料・設計判断

ConvexPolygon(points)は渡した点集合のstrictな凸包を構築します。vertices()で正規化済みの反時計回りの頂点列をconst参照、contains(q)でLocationを返します。凹多角形を渡すとその凸包の内部を判定するため、凹領域の判定にはpoint_in_polygonを使います。

すでにstrictなCCW凸包があるならconvex_polygon_contains(hull,q)で構築を省略できます。先頭からの扇形を二分探索します。問い合わせごとに全頂点を検査しないため、反時計回り・共線の途中点なし・凸・末尾の重複なしが呼出し側の前提です。開始頂点は任意。空・一点・線分の扱いは一般多角形版と同じです。

浮動小数点版クラスはConvexPolygon(points,Tolerance)で誤差を保存し、構築と問い合わせで共用します。free関数は末尾Toleranceを指定します。曖昧な小さな角がないことも数値上の条件になります。

usage #

#include <iostream>
#include <vector>
#include "computational_geometry/polygon.hpp"
namespace e=cp::geometry::exact;
namespace f=cp::geometry::floating;
int main(){
    e::ConvexPolygon p({{0,0},{3,0},{3,3},{0,3},{1,1}});
    std::cout<<static_cast<int>(p.contains({1,1}))<<' '<<static_cast<int>(p.contains({4,1}))<<'\n';
}

実行できる例。整数・浮動小数点の型とnamespaceは混ぜず、使用する方を明示してください。

条件・計算量 #

構築 O(n log n)・問い合わせ O(log h)・保持 O(h)。整数はGCC/Clangの検査付き128ビット演算です。有理数の正規化・比較にはO(log M)の整数演算を要し、上の計算量はこれを基本演算一回として数えています。中間値の範囲・浮動小数点の誤差と例外は共通仕様を参照してください。
