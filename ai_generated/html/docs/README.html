3.xx ごとに1つの独立したカテゴリフォルダを用意します。説明はコードと同名の Markdown として、docs/<カテゴリ>/ に配置します。

union_find/                 # 3.2 の実装
docs/union_find/            # 同じ名前の .md とカテゴリ索引
visualizations/union_find/  # 図を操作できるアルゴリズム解説
examples/union_find/        # コンパイルして動かす使用例
verify/union_find/          # 差分テスト・ジャッジ形式のプログラム

以降の各アルゴリズムの説明には、次を揃えます。

  1. 何を解くか、使用条件、API。
  2. 最小の usage と動く使用例。
  3. 構築・操作・メモリの計算量。
  4. 使用する問題へのリンク、検証済み範囲。
  5. 原理・境界条件・実装上の注意点。
  6. 図解を組み合わせたインタラクティブな解説。
  7. 参考にした一次資料。

ヘッダ内には短い用途・重要な契約・説明への場所だけを残し、長い説明は移します。実装を Markdown に複製しません。documentation_of: //カテゴリ/ファイル.hpp により、公開用ドキュメント生成時に説明と実装を紐付けられます。

インタラクティブ解説の実装言語は問いません。visualizations/ に独立して置き、各説明・カテゴリ索引・共通の解説一覧 から参照できるようにします。現状の HTML はローカルで直接開ける形式です。公開時には visualizations/ と実装・Markdown を同じルート構成で配置します。

木の追加項目 #

T-01〜T-03・T-20〜T-23のAPI・検証 / 7モードの図解。木の中心・Prüfer符号・根変更区間と、link/cutを伴うTop Tree・lazy・部分木集約・木DPを追加しました。make verify-tree-extensionsでまとめて検証できます。

グラフ追加G-01〜G-15のAPI・検証を追加しました。区間辺・被覆・カット木・st順序・平均閉路・次数列・暗黙/増分MST・なもり・反鎖・辺彩色・差分制約・負閉路・最小費用素パスを扱います。

G残り15項目のAPI・検証を追加しました。Cost Scaling、少種類重み/群ラベル最短路、最小直径木、SPQR、一般木幅、cograph標準形、重み付き/順位matching、動的単位容量フロー、連結/強連結/Euler計数、厳密同型、二端子直並列分解を扱います。make verify-graph-advancedで検証できます。

P全14項目のAPI・検証を追加しました。Frontier・bit並列LCS/Myers・Exact Cover・A*/IDA*/双方向BFS・SAT・ナップサック復元と個数・Monge積・重み付きSlope Trick・動的DP・少種類重量Knapsack。14モードの図解。make verify-dp-extensions。

N全19項目のAPI・検証を追加しました。区間篩・位数・多項式Floor Sum・逆元・巨大二項係数/階乗・再利用BSGS・mod根・Gaussian整数・連分数/Pell/二平方数和・商prefix・素数和・Min_25・重み付きmod和。19モードの図解。make verify-number-theory-extensions。
