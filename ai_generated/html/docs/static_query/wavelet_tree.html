Wavelet Tree

圧縮した値域を二分する木です。各節点に左の子へ進む要素数のprefixを持ち、位置区間を子の区間へ写します。

使用例 #

#include <iostream>
#include "static_query/wavelet_tree.hpp"
int main() {
    cp::WaveletTree<int> s({4,1,4,2});
    std::cout << *s.kth_smallest(0,4,2) << "\n";
}

出力: 4。

APIと使用条件 #

WaveletTree<T>(vector)、count_less(l,r,x)、range_freq(l,r,lower,upper)、kth_smallest(l,r,k)はoptional、size。

静的配列、比較は<のみ。rankは0始まり、区間が空／rankが範囲外ならnullopt。Wavelet Matrixとは節点ごとの列を保持する別実装です。

計算量 #

構築O(N log(N+1))、領域O(N log(σ+1)+σ)、検索O(log(σ+1))。 演算・比較・値のコピーが O(1) の場合です。文字列などを格納すると、その処理時間・領域が加わります。

使用する問題と検証 #

静的な列の区間頻度・k番目の値に使います（更新はできません）。検証では、長さ0〜179の配列でrange_freq・count_less・kth_smallestを全探索と比較し（空区間はnullopt）、operator<だけを持つキー型でも動くことを確認します。

python3 verify/run_b_1_6.py（--sanitize 対応）で単独／重複include、debug/releaseの比較検証、上の使用例を確認します。検証範囲の詳細は追加分の一覧。オンライン提出・ACは未確認です。
