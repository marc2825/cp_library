Dynamic Bitset

実行時長のbit列をuint64の配列に格納し、word単位の集合演算とshiftを行います。最後のwordの未使用bitを常に0に保ちます。

使用例 #

#include <iostream>
#include "static_query/dynamic_bitset.hpp"
int main() {
    cp::DynamicBitset s(130); s.set(63); s.set(64);
    std::cout << (s<<1).find_next(64) << " " << s.count() << "\n";
}

出力: 64 2。

APIと使用条件 #

DynamicBitset(size_t n=0,bool value=false)、size()、test(p)、set(p,value=true)、flip(p)、reset/count/any、&,|,^,~と&=,|=,^=、<<,>>、find_next(p=0)。

二項演算は同じ長さ同士。shift>=Nは全0。find_nextはp以上の最初の1、未発見はsize()。0長、64境界、size_tの大きいshiftも可。

計算量 #

点操作O(1)、bit演算・shift/count O(ceil(N/64))、find_nextは探索word数、領域O(ceil(N/64))。 演算・比較・値のコピーが O(1) の場合です。文字列などを格納すると、その処理時間・領域が加わります。

使用する問題と検証 #

実行時に長さが決まるビット集合の演算（部分和DPのシフト、集合の積・和など）に使います。検証では、境界の長さ（0, 1, 63, 64, 65, 127, 128, 129, 1000）と両方向のシフトについてvector<bool>と比較し、全位置からのfind_nextと各演算後のcountも確認します。

python3 verify/run_b_1_6.py（--sanitize 対応）で単独／重複include、debug/releaseの比較検証、上の使用例を確認します。検証範囲の詳細は追加分の一覧。オンライン提出・ACは未確認です。
