Möbius μ

平方因子の有無と素因数個数から、Möbius関数を計算します。

実装 / 操作できる図解 / カテゴリ一覧 / 補完項目・検証

API・使用条件 #

mobius(uint64_t n) → -1/0/1、mobius_sieve(int limit) → vector（添字0..limit）。

n>=1、mu(1)=1。篩の0は便宜上0。単一値の0・負の篩上限はinvalid_argument。単一値は既存64bit素因数分解を共有します。

原理と計算量 #

同じ素因数が二度現れれば0、そうでなければ異なる素因数の個数だけ符号反転します。篩ではi=p*qでpがqを割れば0、それ以外は-mu(q)。

篩O(N)時間/O(N)領域。単一値はPollard–Rhoの素因数分解時間に従い、最悪時間保証はありません。

使用例 #

#include <iostream>
#include <vector>
#include "number_theory_basic/mobius.hpp"

int main() {
    auto values=cp::mobius_sieve(12);
    std::cout << cp::mobius(30) << " " << values[12] << "\n";
}

出力:

-1 0

動く使用例。C++17でリポジトリルートをincludeパスに指定します。

問題例・検証範囲・参考資料 #

使用問題: 約数包除と既存のGCD畳み込み。

python3 verify/run_math_a.py と --sanitize で、使用例・単独/重複include・複数翻訳単位・素朴解との比較を実行します。独立した検証では1〜2,500の全 n で Σ_{d|n}μ(d)=[n=1] と篩・単一値の一致を確かめ、2^64−59 で μ=−1、篩の上限0、0と負の上限の例外も確認します。オンラインACは未確認です。図解は小さい入力向けの教材で、数値範囲と簡略化は図の仕様を参照してください。
