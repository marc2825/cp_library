Primitive Root

素数を法とした乗法群の最小の正の原始根を求めます。

実装 / 操作できる図解 / カテゴリ一覧 / 補完項目・検証

API・使用条件 #

primitive_root(uint64_t p) → uint64_t。p=2では1。それ以外の素数では2以上の最小の候補を返します。

pは素数。既存Miller–Rabinで検査し、合成数はinvalid_argument。p-1を既存Pollard–Rhoで分解します。uint64_t全域が対象ですが、探索時間の最悪保証はありません。合成数法の単元群を生成する入口は対象外です。

原理と計算量 #

p-1の異なる各素因数qについてg^((p-1)/q)!=1を検査します。全部通る候補だけが位数p-1を持つため、昇順に試した最初が最小の原始根です。

p-1の素因数分解＋G個の候補、異なる素因数個数wについてO(Gwlog p)回の安全なmod乗算。mod乗算自体は最大O(log p)。追加領域は因数分解に従います。

使用例 #

#include <iostream>
#include <vector>
#include "number_theory_basic/primitive_root.hpp"

int main() {
    std::cout << cp::primitive_root(17) << "\n";
}

出力:

3

動く使用例。C++17でリポジトリルートをincludeパスに指定します。

問題例: Library Checker Primitive Root。

python3 verify/run_math_a.py と --sanitize で、使用例・単独/重複include・複数翻訳単位・素朴解との比較を実行します。独立した検証では4,000以下の全素数で返値が乗法群全体を生成し、より小さい全候補の位数が p−1 未満（最小性）であることを確かめ、合成数15の例外も確認します。ジャッジ形式は300未満の素数10個×24回を照合します。オンラインACは未確認です。図解は小さい入力向けの教材で、数値範囲と簡略化は図の仕様を参照してください。
