Garner

任意個の互いに素な法のCRT解を、指定した法で取得します。

実装 / 操作できる図解 / カテゴリ一覧 / 補完項目・検証

API・使用条件 #

garner(residues,moduli,target_mod) → long long。入力法の積未満の最小非負CRT解をtarget_modで割った剰余。

各入力法とtarget_modは正、入力長は一致し、入力法はpairwise coprime。target_modは入力法と共通因子があっても可。法1・負の剰余・空入力（0）に対応。不正条件はinvalid_argument。入力法の積は64bitに収まらなくてもよく、最小解の整数全体は構築しません。

原理と計算量 #

混合基数の桁を順に確定し、後続の法ごとの定数項と係数を更新します。最後にtarget_modを置きますが、その位置では逆元を求めません。このため出力法と入力法の互いに素性は不要です。

O(K^2)回のmod乗算とO(K)回の逆元、O(K)領域。大きなmod乗算は加算倍増にO(log M)。

使用例 #

#include <iostream>
#include <vector>
#include "number_theory_basic/garner.hpp"

int main() {
    std::cout << cp::garner({2,3,2},{3,5,7},12) << "\n";
}

出力:

11

動く使用例。C++17でリポジトリルートをincludeパスに指定します。

問題例・検証範囲・参考資料 #

使用問題: 任意modのCRT復元。既存の任意mod畳み込みは固定3法の高速な内部処理を保持します。

python3 verify/run_math_a.py と --sanitize で、使用例・単独/重複include・複数翻訳単位・素朴解との比較を実行します。独立した検証では互いに素な法1〜18の対を出力法1,2,7,25で全探索と比較し、空入力、互いに素でない法・出力法0の例外を確かめます。2^61−1までの素数法を最大12個使う1,000件は Python の任意精度と照合します。オンラインACは未確認です。図解は小さい入力向けの教材で、数値範囲と簡略化は図の仕様を参照してください。

参考: ACL CRTの契約、既存の固定法復元。全体の設計判断は一次資料一覧に記載しています。
