3.13 数論：基本整数演算

C++17・namespace cp。まとめて使う場合は all.hpp、個別のヘッダも単独でincludeできます。

用途 実装と説明 主な条件・戻り値
最大公約数・最小公倍数 GCD/LCM 符号付き入力、符号なしの非負結果。LCMの超過はnullopt
Bézout係数 拡張Euclid ax+by=g、負数・最小整数も可
法を取った累乗・乗算 mod累乗 指数>=0、法>=1、積のあふれを回避
法を取った除算 mod逆元 逆元なしはnullopt、合成数法も可
範囲内の素数判定・列挙 素数篩 上限を含む表、0・1は非素数
多数の素因数分解 SPF 線形前処理、表の上限以下を分解
単発の素因数分解 試し割り 正整数、(素数,指数)を昇順
正の約数 約数列挙 正整数、重複なし・昇順

操作できる図解：8モード / 使用例 / 一次資料・設計判断

篩とSPFの上限は両端を含む [0,N] です。分解・約数列挙の0以下は例外で拒否します。1の素因数分解は空、約数は {1} です。GCDと拡張Euclidは LLONG_MIN の大きさも返すためGCDを符号なし型にします。一般の符号なし64ビット入力を受け取るAPIではありません。

法は long long の正整数全域を扱います。一般の大きな法の乗算には最大約63回の加算が必要ですが、法が2^32以下なら積を直接計算できます。試し割り・約数列挙はO(√n)なので、大きい素数が入力される用途では計算量を先に確認してください。

旧 number_theory/ の関数・ファイルは保持しています。新APIは名前空間、上限・例外条件、符号・戻り値を明示しており、旧関数の別名ではありません。旧Eratosthenesの0・1入力や、旧分解の0入力の動作を引き継ぐものではありません。

追加A項目（2026-10-17） #

  • Euler φ — 単一の64bit整数と、上限までの全整数についてEulerのφ関数を求めます。
  • Möbius μ — 平方因子の有無と素因数個数から、Möbius関数を計算します。
  • CRT / 一般化中国剰余定理 — 互いに素でない正の法も含む連立合同式を解きます。
  • Garner — 任意個の互いに素な法のCRT解を、指定した法で取得します。
  • Floor Sum — 負の係数にも対応し、一次式を割って床を取った総和を求めます。
  • Primitive Root — 素数を法とした乗法群の最小の正の原始根を求めます。

追加分の契約・検証範囲 / 18モードの図解。追加分は python3 verify/run_math_a.py / --sanitize で検証します。既存APIとカテゴリ検証は保持します。
