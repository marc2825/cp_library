Bit-parallel LCS

P-02の対応表・検証 / 操作できる図解 / ヘッダ

bit_parallel_lcs_length(string_view a, string_view b) はLCS長をsize_tで返します。NUL・上位bitを含む256種類のバイト列で、UTF-8の文字単位ではありません。短い列をbit列に選び、各バイトの出現位置maskを前計算します。長さ64の制限はなく、word間のshift carryと減算borrowを伝播します。

LCS表の隣接差分をbitで持ち、x = row | mask、y = (row << 1) | 1、row = x & ~(x-y) を更新します。最終rowのpopcountが長さです。空列の答えは0。任意の比較関数・一致添字の復元が必要なら既存のlcsを使います。

n=max長、m=min長、B=ceil(m/64)。時間O(nB+m+256B)、領域O(256B)。m=0はO(1)。用途: 長いバイト列の類似度、LCS長のみの問い合わせ。63/64/65等のword境界・ランダム256バイト・10万文字を比較検証します。

使用例 #

#include <iostream>
#include "dp_optimization/bit_parallel_lcs.hpp"
int main() {
    std::cout << cp::bit_parallel_lcs_length("ABCBDAB", "BDCABA") << '\n';
}

出力:

4
