Min-Plus Convolution（凸・凹）

カテゴリ索引 / B項目の対応表 / 操作できる図解 / 実装 / 一次資料と設計

既存の凸列版に加え、凹列同士と任意列×凹列のMin-Plus、および凹列同士のMax-Plusを提供します。

usage #

#include <iostream>
#include "dp_optimization/min_plus_convolution.hpp"
int main() {
    auto c=cp::min_plus_convolution_arbitrary_concave(std::vector<long long>{3,1,4},std::vector<long long>{0,3,4});
    std::cout << c[2] << '\n';
}

出力:

4

API・使用条件 #

min_plus_convolution_convex_convex(a,b)、_arbitrary_convex、_convex_arbitrary、_concave_concave、_arbitrary_concave、_concave_arbitrary。max_plus_convolution_concave_concaveも同梱。入力vector、返値c[k]=min/max_{i+j=k}(a[i]+b[j])。空があれば空。凸は差分が非減少、凹は非増加。

仕組み・境界条件 #

凸×凸は小さい傾きをmerge。凹×凹の最小値は各反対角線の端点にあります。任意×凹は任意列を長さM以下に分割し、前半／反転後半それぞれで凹カーネルの部分包絡をdequeへ保持します。新候補が勝つprefixの境界を二分探索します。形状条件の検査は行わず利用者の前提。標準整数の加算超過はoverflow_error、符号反転を使わないためLLONG_MINも和が入れば扱えます。既存詳細も保持。

計算量 #

凸×凸・凹×凹はO(N+M)、任意×凸はO((N+M)log(N+M))、任意×凹はO(N log(M+1)+M)。出力を含む領域O(N+M)。

使用する問題・検証 #

Min Plus Convolution (Convex and Arbitrary)、凹と任意。 動く小問題。

python3 verify/run_b_12_15.py / --sanitize。検証は長さ30未満の凸・凹・任意列800組で、凸×凸・任意×凸・凹×凹・任意×凹の Min-Plus と凹×凹の Max-Plus を定義どおりの O(NM) 計算と比較し、ジャッジ形式は凹×任意の24入力（長さ100未満）を Python の全添字対と比較します。使用例は文書中のコードと一致を検査してコンパイル・実行します。オンライン提出・ACは未確認です。図解の小入力化と代替計算は図解の範囲に明記しています。
