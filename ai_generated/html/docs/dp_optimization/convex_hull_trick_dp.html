Convex Hull Trick DP

二乗距離のDPを直線の追加・最小値問い合わせへ変形します。

実装 / 操作できる図解 / カテゴリ一覧 / 補完項目・検証

API・使用条件 #

旧APIのCHT_min<long long>::add(a,b)とquery(x)をそのまま使用します。 新しいCHT/木を複製せず、以下の使用例でDPへ組み込みます。

旧CHTはnamespace cp外です。任意順の傾きと問い合わせに対応します。係数の符号反転、差、交点の整数除算、全評価の積と和がlong longに収まることが必要です。LLONG_MINの否定も不可。旧実装の数値契約を拡張していません。 DP側の平方・和も利用者が型内に収めます。例は非空列、dp[0]=0です。

原理と計算量 #

dp[i]=min_{j<i}(dp[j]+(h[i]-h[j])^2+C)を展開すると、傾き-2*h[j]、切片dp[j]+h[j]^2の直線の最小値にh[i]^2+Cを足す形です。問い合わせてからiの直線を追加し、自分への遷移を防ぎます。

N個の直線と問い合わせでO(N log N)時間/O(N)領域。元のDPのO(N^2)と比較検証しています。

使用例 #

#include <iostream>
#include <vector>
#include "data_structure/ConvexHullTrick.hpp"

int main() {
    std::vector<long long> h{10,30,20},dp(h.size());
    CHT_min<long long> lines;
    for (int i=0;i<static_cast<int>(h.size());++i) {
        if (i) dp[i]=lines.query(h[i])+h[i]*h[i]+10;
        lines.add(-2*h[i],dp[i]+h[i]*h[i]);
    }
    std::cout << dp.back() << "\n";
}

出力:

110

動く使用例。C++17でリポジトリルートをincludeパスに指定します。
