Mongeの辺数制約付き最短路

カテゴリ索引 / B項目の対応表 / 操作できる図解 / 実装 / 一次資料と設計

ちょうどK辺のDP各段をSMAWKで計算し、K本の辺からなるパスを復元します。

usage #

#include <iostream>
#include "dp_optimization/monge_shortest_path_k_edges.hpp"
int main() {
    auto r=cp::monge_shortest_path_k_edges(5,2,[](int i,int j){return 1LL*(j-i)*(j-i);});
    std::cout << r->cost << ' ' << r->vertices.size()-1 << '\n';
}

出力:

13 2

API・使用条件 #

monge_shortest_path_k_edges(n,k,cost)→optional{cost,vertices}。頂点0..n、全i<jに有限long longのMonge費用。n,k>=0、K>NまたはK=0,N>0はnullopt。N=K=0は{0,{0}}。

仕組み・境界条件 #

各段の全単調な行最小値を一括計算する方式です。罰則の二分探索ではないため、探索範囲や同点の辺数の選び方を指定する必要はありません。Nが大きくKも大きい場合は時間・復元表を見積もってください。Monge条件は利用者の前提、加算超過はoverflow_error。

計算量 #

O(KN)回のcost評価と時間、復元表の領域O(KN)。

使用する問題・検証 #

区間をちょうどK個へ分割するDP。 動く小問題。

python3 verify/run_b_12_15.py / --sanitize。検証は同じ700入力と K<N+3 で O(KN²) の辺数別DPと値・nullopt を比較し、復元経路が狭義増加・K辺・0→N・費用一致であることを確かめます。使用例は文書中のコードと一致を検査してコンパイル・実行します。オンライン提出・ACは未確認です。図解の小入力化と代替計算は図解の範囲に明記しています。
