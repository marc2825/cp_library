Aliens Trick / WQS Binary Search

個数への罰則付き最適化から、ちょうどK個を使う離散凸DPの値を求めます。

実装 / 操作できる図解 / カテゴリ一覧 / 補完項目・検証

API・使用条件 #

aliens_trick(k,low,high,oracle) → optional。oracle(penalty)はPenalizedDPResult {value,count}としてmin_j(F(j)+penalty*j)とその個数を返します。結果のvalueはF(k)、penaltyは採用した罰則、relaxedはoracleの結果です。

Fは実行可能な個数の連続区間上で離散凸、Fと罰則は整数です。罰則の同値解は必ず個数が多い方を返し、countは非負。探索端点はcount(low)>=K>=count(high)を満たす必要があり、満たさなければnullopt。凸性・oracleの最適性は検査しません。一般の非凸DPではこの値をexact-K解として使えません。

不正なK/範囲/負countはinvalid_argument。penalty*Kと補正値を含むlong long計算の超過はoverflow_error。oracle内部の計算も呼出側の責任です。

原理と計算量 #

罰則を増やすと最適個数は非増加です。count>=Kとなる最後の整数罰則で、支持直線の値からpenalty*Kを引きます。離散凸性と整数性により、同値でKを飛び越えても正しいF(K)を得られます。

罰則幅WについてO(log(W+1)+1)回のoracle呼出し、追加領域O(1)。signed 64bit全域をまたぐ二分探索にも対応。

使用例 #

#include <iostream>
#include <vector>
#include "dp_optimization/aliens_trick.hpp"

int main() {
    auto oracle=[](long long p) {
        cp::PenalizedDPResult best{1000000,0};
        for (int k=0;k<=6;++k) {
            long long value=(k-3)*(k-3)+p*k;
            if (value<=best.value) best={value,k};
        }
        return best;
    };
    auto result=cp::aliens_trick(2,-20,20,oracle);
    std::cout << result->value << "\n";
}

出力:

1

動く使用例。C++17でリポジトリルートをincludeパスに指定します。
