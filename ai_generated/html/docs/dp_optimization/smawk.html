SMAWK

カテゴリ索引 / 図解 / 実装 / 一次資料・設計判断

usage #

#include <iostream>
#include "dp_optimization/smawk.hpp"
int main() {
    auto a = cp::smawk(4, 6, [](int r, int c) { return (r - c) * (r - c); });
    for (int c : a) std::cout << c << ' ';
    std::cout << '\n';
}

実行できる使用例。C++17、namespace cp。ライブラリルートをincludeパスに追加してください。

API・使用条件 #

smawk(rows,cols,get)->vector<int>。全単調な行列の最左行最小位置を返します。全ての部分行列で最左argminが単調非減少であることが必要で、行列全体のargmin単調性だけでは不十分。Monge行列なら可。getは任意順に呼出されても値が変わらないこと。最左同点、0行／0列／負次元の仕様はMonotone Minimaと同じ。

計算量・原理 #

O(rows+cols)回の値評価・比較、O(rows+cols)補助領域。getの費用は別。

候補列を行数以下へreduceし、奇数位置の行を再帰的に求め、偶数位置の行を隣の解の間だけ走査します。同点で古い列を消さず最左解を保ちます。

使用する問題・検証 #

関連問題。帯状 Monge 行列 a[i]+b[k−i] の行最小として解けますが、帯の外の扱いを含む完成版はmin_plus_convolution_arbitrary_convexです。

追加分の検証入口で、(r−c)²+offsets[c]+row[r] 型の Monge 行列700個（70×60未満）を素朴な最左 argmin と比較し、評価回数が20(rows+cols)以下であること、50×50までの全要素が同値の行列で最左の0を返すこと、負の次元のinvalid_argumentも確かめます（verify/advanced/algebra_test.cpp）。満たさない行列でも範囲内の列を返しますが、最小とは限りません。実際の範囲は検証一覧を参照。オンライン提出のACは未確認です。

図解は学習用の小さい入力で内部状態・候補・論理的な操作を追えます。簡略化の範囲を参照してください。
