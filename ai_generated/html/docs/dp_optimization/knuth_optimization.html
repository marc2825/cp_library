Knuth Optimization

分割点の二方向の単調性を使い、区間DPを二乗時間にします。

実装 / 操作できる図解 / カテゴリ一覧 / 補完項目・検証

API・使用条件 #

knuth_optimization(n,cost) → 既存のIntervalDPResult。dp[l][r]=min_{l<k<r}(dp[l][k]+dp[k][r])+cost(l,r)。長さ0/1は0。splitは最左の分割点、value()は全体の費用、merge_order()は子から親への{l,k,r}列です。

最左optがopt[l][r-1]<=opt[l][r]<=opt[l+1][r]を満たすこと。costが区間包含について単調かつ四辺形不等式を満たすことが十分条件です。costはkに依存しません。非負のSlimesの区間和が典型例。負の次元はinvalid_argument、DP加算の超過はoverflow_error。前提は自動検査せず、満たさない場合も例外にはならず、有効だが最適とは限らない分割を返します。

原理と計算量 #

長さ順に区間を埋め、前の長さで得た左右の分割点の間だけを走査します。探索幅は区間ごとではなく全体で望遠和になり二乗時間です。結果型はinterval_dpと共有します。

costがO(1)ならO(N^2)時間/O(N^2)領域。復元O(N)。

使用例 #

#include <iostream>
#include <vector>
#include "dp_optimization/knuth_optimization.hpp"

int main() {
    std::vector<long long> prefix{0,10,30,60};
    auto result=cp::knuth_optimization(3,[&](int l,int r) {return prefix[r]-prefix[l];});
    std::cout << result.value() << " " << result.merge_order().size() << "\n";
}

出力:

90 2

動く使用例。C++17でリポジトリルートをincludeパスに指定します。

問題例: AtCoder DP N - Slimes。

python3 verify/run_math_a.py と --sanitize で、使用例・単独/重複include・複数翻訳単位・素朴解との比較を実行します。独立した検証は非負の区間和費用で N<22 の550入力について interval_dp と dp・split・merge_order の一致を確かめ、加算超過のoverflow_errorと、N=700 で cost の呼び出しが50万回未満であることも検査します。ジャッジ形式は Python の O(N³) 区間DPと24入力で比較します。オンラインACは未確認です。図解は小さい入力向けの教材で、数値範囲と簡略化は図の仕様を参照してください。
