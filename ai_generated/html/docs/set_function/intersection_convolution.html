API・使用条件 #

intersection_size_convolution<Mod>(f,g) → [intersection_size][union_mask]。

長さは同じ正の2冪。今回の具体化はA∪B=S、|A∩B|=kの係数集約。小標数も可。

C++17、namespace cp。係数列は昇冪です。多項式を正規化するAPIでは末尾0を除き、ゼロ多項式を空配列で返します。FPS・畳み込み・変換の出力長は各APIの精度や入力長に従います。通常のmod係数は負数を正規化して返します。個別ヘッダと所属カテゴリの all.hpp から利用できます。NTTを共有するAPIの既定は Mod=998244353, Root=3、元のNTTの素数・原始根・容量条件を引き継ぎます。64bit/GF/複素数の係数型と規約は上記の専用APIに従います。

入力形状の不一致は invalid_argument、代数的な前提違反は domain_error、長さ・明示的予算超過は length_error です。NTT容量検査が先に行われる場合は代数的前提の検査より先に length_error となります。メモリ割当失敗は標準例外に従います。

原理・計算量 #

rank別zeta表の多項式積をMöbius反転し、rank総和−|S|を交差サイズとして読む。k=0は通常subset convolution。

O(b²2^b)時間・O(b2^b)領域。 ここで M(n) はNTT多項式積の時間です。実用上の上限は計算量・パディング・領域から判断してください。

使用例 #

コンパイルして動かすソース。

#include "set_function/intersection_convolution.hpp"
#include <iostream>

template <class T> void print(const std::vector<T> &a) {
    for (std::size_t i = 0; i < a.size(); ++i)
        std::cout << (i ? " " : "") << a[i];
    std::cout << '\n';
}
int main() {
    auto result = cp::intersection_size_convolution({1, 2, 3, 4}, {1, 1, 1, 1});
    for (const auto &row : result)
        print(row);
}

出力:

1 3 4 10
0 2 3 13
0 0 0 4
