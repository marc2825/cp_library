適用範囲 #

文字列はbyte・半開区間。静的Suffix TreeはSA/LCPから構築し、動的ハッシュには衝突があります。幾何は整数の検査付き128bit/有理数とlong doubleを分離。半平面交差は明示的な境界矩形の中の共通部分で、逐次切断O(H²)です。

重み付き独立集合は1マトロイドの貪欲法と一般グラフ64頂点の厳密分枝限定を区別します。線形パリティは小規模の決定的厳密版と確率的代数版を併記し、後者は返す集合の独立性を検査しますが最大性の失敗確率があります。Partizanは有限short gameと明示した資源上限内の操作。探索は最適性・改善・未知seedでの品質を保証しません。詳細な計算量・数値条件は個別説明を参照してください。

  • 文字列：長さ12まで全二値列のRuns・回文分割・巡回シフト、静的Suffix TreeとKMP、任意byte・両側wildcard、7000回の動的編集、NUL/FFを含む全substring対、3万/10万byteの境界。

  • マトロイド・ゲーム：全subsetの独立性・重み、法3の全subset rank、代数版の実行可能性、4局面までの全有向グラフ、全幅Nimber、左右の完全ゲーム木によるPartizan値の差とoutcome。

  • 4ジャッジ形式：Runs、Wildcard、AOJ円-直線/円-円。各24入力をPythonの独立な整数/浮動計算とdebug/releaseで比較します。ヒューリスティックの架空PROBLEMは付けません。
