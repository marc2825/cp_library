3.7〜3.11 A項目の一次資料・問題例

2026-10-17確認。追加コードは既存のGraph・距離の算術補助・Radix Heap・SCC・二重連結分解・Dinic・BinaryLiftingを共有し、各APIと検証をこのリポジトリ向けに整備しています。

対象 一次資料・問題例 設計判断
Radix Dijkstra iwiwi/radix-heap、AOJ GRL_1_A 旧ヒープを共有。距離は符号なしキーで格納し、親と元辺IDを返す。
Dial・DAG Shortest Path問題 DialはC+1個の循環バケット。DAGは閉路を拒否してトポロジカル順に負辺も緩和。
Johnson AOJ GRL_1_C 全点を初期値0とするBellman–Ford、整数reweight、元辺IDを保った復元。
単純なK-shortest Luzhiled: K Shortest Path Yen法。頂点を重複させず、多重辺をIDで区別。接頭辞trieで禁止辺を共有し全経路列挙と比較。
K-shortest walk Luzhiled: K Shortest Walk、Library Checker Eppstein法。整数indexの永続leftist heapとsidetrack履歴でメモリを所有し、walkは遅延復元。
Functional Graph Nyaan: Functional Graph、CSES Planets Queries II 入次数の剥がしで閉路と流入木を分解。64bit jumpは既存部品、最小遷移回数も公開。
Block-Cut 既存の二重連結分解、Biconnected Components 元頂点を全て保持する所属関係の森。既存公開APIを再実装しない。
2-SAT ACL公式仕様、Library Checker 節の真偽値指定を明確にし、既存の反復SCCから割当を復元。
Eulerian Trail Library Checker有向版、無向版 Hierholzer法を反復実装。論理辺ID、自己ループ、離れた辺成分、指定始点を検証。
下限/選択フロー ACL公式MaxFlow仕様、AtCoder ABC193 F Dinicを共有。下限は頂点需要へ変換し、s-tの負のvalueも許容。選択問題は費用/罰金/必須条件を分離し、soft総和+1で必須条件を扱う。
木ハッシュ Nyaan: Tree Hash、Rooted Tree Isomorphism Classification 高さごとのsaltと子の積、部分木サイズ、二重mod。非根付きは重心から計算。反復走査と固定seed、衝突の限界を明記。

参考実装のAC表示をこの追加コードのACとして扱いません。6形式のローカル検証はverify/graph_aに置き、非一意の割当/道は出力を解析して条件そのものを確認します。
