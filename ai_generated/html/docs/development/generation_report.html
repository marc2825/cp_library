生成ライブラリ・検索カタログの対応状況

API・対応制約 / JSON・CLI・stress / 全機能検索 / JSONカタログ

主な追加先は ai_generated/tools/cp_tools/ です。依存パッケージを増やさず、既存Random・Graph・stress・ヘッダメタデータを再利用しています。

完了した範囲 #

  • P0: 任意精度整数、複数整数・タプル、依存スカラー、配列・文字列、制約検査、出力分離、再現性、CLI、機能索引・README導線。
  • P1: 基本行列・到達性グリッド・木・疎グラフ・区間・クエリ、複数ケース、総和・二乗和予算、特殊分布、JSON、既存stress接続。
  • P2の一部: 状態付き集合・多重集合・スタック・キュー・辺操作、拡張callback、正しい括弧列、回文・アナグラム。
  • P3の一部: O(N²)候補列挙を避ける新グラフAPI、カタログ自動収集・検査、実行例22項目、性能測定スクリプト、CIへの追加。

P1の全制約組合せへの対応ではありません。各APIが保証する構成と制限はAPI説明に記載しています。

未実装・一部対応 #

一般制約ソルバー、行和と列和の同時指定、一般迷路・島数、任意次数・指定SCC数、負閉路の有無の保証、 高度な文字列条件、素数・GCD/LCM専用サンプラー、一般幾何配置、制約を保つ縮小器、ストリーミング出力は未実装です。 幾何は既存の凸多角形生成を再利用します。総予算は独立整数のsum範囲と二乗和上限まで対応します。 任意predicate・JSON constraintsは試行回数に上限があり、予算切れを不可能と断定しません。

互換性と改善候補 #

既存関数シグネチャとbelowの上限制約、64bit範囲内の整数乱数消費を維持します。 旧グラフ生成器は既存の小・中規模APIとして残し、大規模用途には新APIを追加しました。 カタログのC++登録単位は公開ヘッダです。全メソッドの自動抽出やテスト網羅率の推測は行っていません。 今後は明示的なC++ APIメタデータ、構造別縮小、相互依存する予算、ストリーミングを拡張できます。
