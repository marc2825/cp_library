開発・検証基盤（V-01〜V-04）

制約付き生成API / JSON・CLI・stress連携 / 22項目の実行例 / 機能検索カタログ。 make verify-generation で生成器の性質検査とCLI統合テストを実行できます。

Python 3.10以上のローカル開発ツールです。C++ライブラリのPython移植とは別です。

競プロでの使い方に、任意の作業フォルダから使える tools/cplib.py を追加しました。V-04バンドラを共用し、ヘッダ検索・雛形・依存込み抽出・VS Codeのinclude補完を提供します。

続くV-05〜V-07としてC++デバッグ出力、対話ローカルジャッジ、AHC複数seed並列実行を追加しました。プロセス起動・終了は共通の process.py を使います。

検証 #

カテゴリごとの実行、コンパイラ変更、サニタイザ、共通suiteの使い方はローカル検証ガイドを参照してください。

make verify-development
python3 verify/run_development.py --sanitize
node verify/visualizations/development_model_test.js
node verify/visualizations/development_browser_test.mjs --browser /path/to/chromium

通常検証は標準Python・g++・Boostヘッダで動きます。バンドラの元ファイルと展開後ファイルをDebug/Releaseでコンパイルし、同一入力の出力を比較します。5組の実プログラム、80 seedのC++ DSU対Python探索、生成器の連結性・閉路・幾何条件、異常終了・失敗保存・再実行・timeout・POSIX子プロセス終了を確認します。サニタイザはC++実行にASan/UBSanを付けます。

固定版verifier自体の接続確認は、依存を入れた仮想環境で python verify/run_development.py --with-verifier を実行します。未コミットの追加も検査できるよう、一時ディレクトリに必要なファイルだけをGit snapshotとしてコピーします。実リポジトリのindexは変更しません。standaloneの実行・文書生成・3オンライン問題の設定と依存解決までを検査し、テストケースのダウンロードは行いません。

GitHub上でのworkflow実行、オンライン問題の全ケース実行、公開サイトの配信は別途行う操作です。この追加だけでオンラインACとは扱いません。
