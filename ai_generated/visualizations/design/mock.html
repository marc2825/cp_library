[2, 4) は足す区間に完全に含まれる

子へは降りません。このノードの合計を 7 から 17 に更新し（+5 × 2 要素）、子に伝える分を lazy +5 として残します。

擬似コード

  1. apply(k, l, r, x):
  2. if 区間外(k): return
  3. if 完全に含む(k):
  4. sum[k] += x * 幅(k)
  5. lazy[k] += x
  6. return
  7. push(k)
  8. apply(左の子, l, r, x)
  9. apply(右の子, l, r, x)
  10. sum[k] = sum[左] + sum[右]

呼び出し中：apply [0, 8) → [0, 4) → [2, 4)

押さえること

  • 完全に含まれるノードで止まるので、触るノードは O(log n) 個。
  • 遅延は、あとでその下を見るときに子へ伝える。
